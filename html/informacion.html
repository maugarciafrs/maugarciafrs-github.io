Funciones pricipales del invernadero EcoParadise

¿Que hace?

Eco Paradise es un sistema inteligente diseñado para optimizar el cultivo de plantas en invernaderos, asegurando condiciones óptimas para su crecimiento. Este proyecto integra múltiples tecnologías para crear un ambiente controlado que responde a las necesidades de las plantas.

Iluminación

El sistema cuenta con un módulo de iluminación que simula la luz solar, utilizando un espectro específico para favorecer la fotosíntesis.

Ventilación

Tiene un sistema de ventilación que ajusta la temperatura y la humedad, garantizando un clima adecuado para el desarrollo de las plantas.

Riego automatico

Para el riego, Eco Paradise emplea sensores de humedad del suelo que activan automáticamente la bomba de agua cuando es necesario, asegurando que las plantas reciban la hidratación adecuada sin desperdiciar recursos. Este sistema también incluye notificaciones al usuario, alertando sobre el estado del invernadero y asegurando un monitoreo constante de las condiciones internas.

Placa Principal

La placa principal del proyecto Eco Paradise utiliza un ESP32 para conectar y gestionar los sistemas del invernadero: las luces de crecimiento se activan con iluminación magenta según sensores LDR y un horario; la ventilación se controla con un sensor DHT11 que enciende un ventilador si la temperatura supera 28 °C o la humedad excede 70 °C; el riego activa una bomba cuando la humedad del suelo baja del 40 % y envía un mensaje por Telegram si el tanque está vacío; y el sistema de estado notifica al usuario sobre el funcionamiento del invernadero. Estos sistemas aseguran un control eficiente del invernadero.

Placa Sensor de Nivel de Agua

El objetivo de esta placa es detectar el nivel de agua de un tanque y activar una bomba según la humedad del suelo. Usa dos integrados: el CD4049, que invierte las señales de los sensores en el tanque para evitar la electrólisis, y el ULN2803, un array de transistores Darlington que amplifica las señales y controla los LEDs que indican el nivel del agua.

Cuando el agua toca un tornillo sensor, el CD4049 invierte la señal y la envía al ULN2803, que activa el LED correspondiente. El estado de los LEDs indica al ESP32 cuándo activar la bomba.

Esquema de mecanizado del ganinete

Este gabinete protegerá las placas principales, incluidas la placa principal y la placa del sensor de nivel de agua, garantizando su seguridad frente a daños externos. Además, permitirá una conexión segura y eficiente de los componentes, sin comprometer la integridad del sistema ni exponerlo a riesgos ambientales.

Partes

GABINETE PARTE LATERAL IZQUIERDO: En esta pieza se hicieron 2 agujeros rectangulares, el de arriba es para conectar los cables de las señales del tanque del agua y el de abajo es para conectar las matrices RGB con su respectiva alimentación.

GABINETE LATERAL DERECHO: Para hacer esta pieza se usó la herramienta de simetría para duplicar el lateral izquierdo y no tener que hacer otro boceto.

GABINETE PARTE FRONTAL: En esta pieza se hizo un agujero rectangular para poder alimentar a la placa principal(que también alimenta a la placa de control de nivel de agua) mediante un cable micro usb B, usando un cargador de celular de 5V 2A.

GABINETE, PLATAFORMAS PARA LAS PLACAS: Entre la parte trasera y delantera se pusieron 2 plataformas para poder anclar las placas. La superior es para la placa del control de nivel del agua y la de abajo es para la placa principal.

GABINETE, TAPA: Se hizo esta pieza para poder dar protección a la placa en la parte superior, además se le hizo un agujero rectangular para que se puedan ver los leds indicadoras del nivel del agua.

Para la unión entre las 4 piezas(delantera, trasera, lateral izquierda y lateral derecho) se hizo el diseño de unos soportes y luego se lo imprimió 4 veces con la impresora 3D, para las esquinas.
